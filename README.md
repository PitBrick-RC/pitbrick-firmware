# PitBrick firmware

Updates for the PitBrick digital setup station for 1:10 touring cars.

**Install / update:** open the update page in Chrome or Edge on a computer, connect the PitBrick with a USB-C data cable and click *Install*. Your settings (sensors, calibration, wifi, language) stay saved.

- NL: open de updatepagina in Chrome of Edge op een computer, sluit de PitBrick aan met een USB-C-datakabel en klik op *Installeren*. Je instellingen blijven bewaard.
- DE: Update-Seite in Chrome oder Edge am Computer öffnen, PitBrick per USB-C-Datenkabel verbinden und auf *Installieren* klicken. Deine Einstellungen bleiben erhalten.

What's new per version: see *Releases*.

More info: [pitbrick.com](https://pitbrick.com)
